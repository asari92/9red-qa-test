# Задача 3: Теория вероятностей

**Условие:** Монету подбрасывают три раза. Какова вероятность того, что выпадет ровно два орла?

## Решение

На каждом броске возможны два исхода: орёл (О) или решка (Р).  
Всего исходов для 3 бросков:

- (2^3 = 8)

Чтобы выпало **ровно два орла**, нужно выбрать, на каких **двух из трёх** бросков выпадает орёл (а на оставшемся будет решка).  
Количество таких вариантов равно числу сочетаний:

- C(3,2)

Вычислим:

- C(n,k) = {n!} / {k!(n-k)!}
- C(3,2) = {3!} / {2!(3-2)!} = {3 * 2 * 1} / {(2 * 1) * 1} = 3

Значит, благоприятных исходов 3 (например: **ООР**, **ОРО**, **РОО**).

## Ответ

[P = {3} / {8} = 0.375]
